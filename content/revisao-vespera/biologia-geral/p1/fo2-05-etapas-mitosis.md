# FO2 — Tema 5: Etapas de la Mitosis

> 🎯 **O que o avaliador quer ver:** uma **sequencia de 5 quadros** (como uma tirinha) mostrando cada fase da mitose com os elementos corretos e a transicao entre elas. O resultado final deve estar explicitamente declarado: **2 celulas diploides (2n) identicas**.

---

## 1. O Mnemonico

> 🧠 **"Prometi a Ana telefonar"**
>
> **Pro**fase → **Pro**metafase → **Meta**fase → **Ana**fase → **Telo**fase

---

## 2. Os 5 Quadros — Sequencia Completa

### Quadro 1 — PROFASE (*Profase*)

```
┌────────────────────┐
│ Nucleo ainda existe│
│  [Cromatina ────]  │  Cromossomos condensam
│   [────cromo────]  │  (cada um com 2 cromatides)
│                    │
│  Huso comeca       │  Fuso mitotico inicia
│  Nucleolo desaparece│  Nucleolo some
└────────────────────┘
```

**Elementos obrigatorios:**
- Cromossomos condensando (visiveis, cada um = 2 cromatides unidas no centromero)
- Carioteca (envelope nuclear) **ainda presente**
- Inicio do fuso mitotico (asters / centrossomos)
- Nucleolo desaparecendo

![[bio-p1-t10-slide-010-mitosis-y-meiosis-pagina-010.jpg]]

---

### Quadro 2 — PROMETAFASE (*Prometafase*)

```
┌────────────────────┐
│  Carioteca          │  Envelope nuclear SE ROMPE
│  ||||    ||||       │  
│  ||||    ||||       │  Fuso penetra no nucleo
│   ╲╲    ╱╱         │
│    cinetocoros      │  Microtubulos se ligam
│    presos           │  aos cinetocoros
└────────────────────┘
```

**Elementos obrigatorios:**
- **Carioteca se rompe** (envelope nuclear se desfaz)
- Cinetocoros aparecem nos centromeros
- Microtubulos do fuso se ligam aos cinetocoros
- Cromossomos comecam a migrar

![[bio-p1-t10-slide-012-mitosis-y-meiosis-pagina-012.jpg]]

---

### Quadro 3 — METAFASE (*Metafase*)

```
┌────────────────────┐
│   Polo             │
│    ╲   ╲   ╱   ╱   │  Fuso completamente formado
│     ═══════════    │  PLACA EQUATORIAL
│     cromossomos    │  Alinhamento maximo
│     alinhados      │  Maxima condensacao
│    ╱   ╱   ╲   ╲   │
│   Polo             │
└────────────────────┘
```

**Elementos obrigatorios:**
- Cromossomos alinhados na **placa equatorial** (*placa ecuatorial*)
- Fuso mitotico completo, com microtubulos em ambos os polos
- **Maxima condensacao** dos cromossomos (mais visiveis)
- Sem carioteca (ela se desfez na prometafase)

![[bio-p1-t10-slide-014-mitosis-y-meiosis-pagina-014.jpg]]

---

### Quadro 4 — ANAFASE (*Anafase*)

```
┌────────────────────┐
│  ═══ Polo ═══      │
│  /  /  /  /        │  Cromatides-irmas SE SEPARAM
│ /  /  /  /         │  e vao para polos opostos
│ \  \  \  \         │
│  \  \  \  \        │  Celula se alonga
│  ═══ Polo ═══      │
└────────────────────┘
```

**Elementos obrigatorios:**
- **Cromatides-irmas** (*cromatides hermanas*) se separam
- Cada cromatide puxada para um polo oposto pelos microtubulos
- Celula se alonga (forma ovalada mais longa)
- Cada polo recebe o mesmo numero de cromossomos

![[bio-p1-t10-slide-016-mitosis-y-meiosis-pagina-016.jpg]]

---

### Quadro 5 — TELOFASE + CITOCINESE (*Telofase*)

```
┌────────────────────┐
│  [nucleo novo]     │  Carioteca reaparece em cada polo
│  cromossomos       │  Cromossomos decondensam
│  decondensam       │  Nucleolo reaparece
│─ ─ ─ ─ ─ ─ ─ ─ ─│  Sulco de clivagem
│  cromossomos       │  (citocinese)
│  decondensam       │
│  [nucleo novo]     │
└────────────────────┘

Resultado final: 2 celulas diploides (2n) identicas
```

**Elementos obrigatorios:**
- Carioteca **reaparece** em cada polo
- Cromossomos **descondensam** de volta a cromatina
- Nucleolo reaparece
- **Citocinese**: celula se divide em duas (sulco de clivagem em animais)
- Resultado: **2 celulas-filhas diploides (2n) identicas** a celula-mae

![[bio-p1-t10-slide-018-mitosis-y-meiosis-pagina-018.jpg]]

## 3. Tabela Comparativa das 5 Fases

| Fase | Carioteca | Cromossomos | Fuso | Evento chave |
|---|---|---|---|---|
| **Profase** | Presente | Condensando | Iniciando | Condensacao |
| **Prometafase** | **Se rompe** | Condensados | Formando | Cinetocoros + captura |
| **Metafase** | Ausente | Alinhados na placa | Completo | Alinhamento equatorial |
| **Anafase** | Ausente | Separando (polo a polo) | Completo | Separacao das cromatides |
| **Telofase** | **Reaparece** | Descondensando | Desmontando | 2 nucleos novos + citocinese |

---

## 4. Checklist — Nao Pode Faltar na Prova

- [ ] **5 fases na ordem correta** com o mnemonico
- [ ] Profase: condensacao, nucleo ainda intacto
- [ ] Prometafase: carioteca **se rompe** — esse e o gatilho
- [ ] Metafase: placa equatorial, **maxima condensacao**, sem carioteca
- [ ] Anafase: cromatides-irmas se separam indo para polos OPOSTOS
- [ ] Telofase: carioteca **reaparece**, citocinese → **2 celulas filhas 2n identicas**
- [ ] Distinguir claramente de MEIOSE: mitose produz 2 celulas diploides identicas; meiose produz 4 celulas haploides

---

## 5. Erros Classicos

> [!warning] Erro 1 — Confundir Metafase com Anafase
> **Metafase** = cromossomos ALINHADOS no meio da celula (ninguem se moveu ainda).
> **Anafase** = cromatides JA SE SEPARANDO em direcao aos polos.
> Dica: "Meta" = meio; "Ana" = apartando.

> [!warning] Erro 2 — Esquecer a Prometafase
> A maioria dos alunos pula direto de Profase para Metafase.
> A Prometafase e a fase em que a carioteca se rompe — e um evento critico.

> [!warning] Erro 3 — Confundir Mitose com Meiose
> Mitose: 1 celula 2n → **2 celulas 2n** identicas (divisao somatica).
> Meiose: 1 celula 2n → **4 celulas n** (divisao germinativa).
> Na prova do FO2, o foco e **mitose** — declarar o resultado explicitamente.

> [!warning] Erro 4 — Dizer que a carioteca desaparece na Profase
> A carioteca desaparece na **Prometafase**, nao na Profase.
> Na Profase ela ainda existe — e so na Prometafase que ela se desfaz.
