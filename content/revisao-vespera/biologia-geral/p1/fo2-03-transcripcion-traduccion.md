# FO2 — Tema 3: Transcripcion y Traduccion

> 🎯 **O que o avaliador quer ver:** **dois desenhos encadeados** — o primeiro no nucleo (transcricao), o segundo no citoplasma (traducao). A fronteira nucleo/citoplasma e um elemento critico que nao pode ser omitido.

---

## 1. Dogma Central da Biologia Molecular

```
DNA → (Transcricao) → RNA → (Traducao) → Proteina
```

> [!note] Narrativa para a Aula
> "Transcricao = fazer a fotocopia da receita (no nucleo).
> Traducao = o cozinheiro lendo a receita e montando o prato, aminoacido por aminoacido (no citoplasma)."

---

## 2. DESENHO 1 — Transcricao (no Nucleo)

### O Esquema

```
NUCLEO
┌──────────────────────────────────────────────────────┐
│                                                      │
│  DNA dupla fita                                      │
│  5'═══════════════════════════════3'  fita codificante│
│  3'═══════════════════════════════5'  fita MOLDE      │
│         ↑                                            │
│    RNA POLIMERASE                                    │
│    (le 3'→5' no molde)                               │
│         ↓ produz                                     │
│  5'─ pre-mRNA (transcrito primario) ─ 3'             │
│                                                      │
│  PROCESSAMENTO DO pre-mRNA:                          │
│  [5' CAP]─[exon1]─(intron eliminado)─[exon2]─[poli-A 3']  │
│              ↑ SPLICING (ayuste)                     │
│  → mRNA MADURO pronto para sair                      │
│                                                      │
│              PORO NUCLEAR                            │
└──────────────────────────────────────────────────────┘
                     ↓
            mRNA maduro vai para o citoplasma
```

![[bio-p1-t09-slide-007-transcripcion-y-traduccion-pagina-007.jpg]]

### Checklist — Transcricao

- [ ] RNA Polimerase na fita molde do DNA
- [ ] Direcao: RNA pol le o molde **3'→5'** e produz o RNA **5'→3'**
- [ ] Uracila (U) no RNA no lugar de Timina (T): A pareia com U
- [ ] pre-mRNA com introns e exons rotulados
- [ ] Splicing: introns eliminados, exons unidos
- [ ] **Cap 5'** e **cauda poli-A 3'** adicionados ao mRNA maduro
- [ ] mRNA sai pelo poro nuclear em direcao ao **citoplasma**

## 3. DESENHO 2 — Traducao (no Citoplasma)

### O Esquema

```
CITOPLASMA
┌──────────────────────────────────────────────────────┐
│                                                      │
│  mRNA:  5'─AUG─cod1─cod2─cod3─STOP─3'               │
│              ↑ inicio (Met)         ↑ termina        │
│                                                      │
│  RIBOSSOMO (subunidade maior + menor):               │
│  ┌─────────────────────────────────┐                 │
│  │  [Sitio E] [Sitio P] [Sitio A]  │                 │
│  │   tRNA-sai  tRNA-pep  tRNA-new  │                 │
│  └─────────────────────────────────┘                 │
│                                                      │
│  tRNA:  ANTICODON pareia com CODON do mRNA           │
│                                                      │
│  Resultado: cadeia de aminoacidos = PROTEINA         │
└──────────────────────────────────────────────────────┘
```

> *Slide CLASE 9 — panorama da traducao: codons do ARNm → aminoacidos do polipeptido:*

![[bio-p1-t09-slide-026-panorama-general-de-la-traduccion.jpg]]

### Checklist — Traducao

- [ ] Ribossomo com os **tres sitios**: E (saida), P (peptidil), A (aceitador)
- [ ] mRNA correndo atraves do ribossomo, de **5'→3'**
- [ ] Codon de **inicio AUG** (codifica Metionina)
- [ ] tRNA com **anticodon** pareando com o codon do mRNA
- [ ] Aminoacidos sendo adicionados a cadeia peptidica
- [ ] Codon de **STOP** (UAA, UAG ou UGA) — libera a proteina
- [ ] Localizacao: **CITOPLASMA** (nao nucleo!)

## 4. Comparacao entre Transcricao e Traducao

| Criterio | Transcricao | Traducao |
|---|---|---|
| **Onde ocorre** | Nucleo (eucariotos) | Citoplasma |
| **Molecula produzida** | RNA (mRNA) | Proteina |
| **Enzima principal** | RNA Polimerase | Ribossomo + fatores |
| **Molde** | Fita de DNA | mRNA |
| **Direcao** | 5'→3' (produto) | 5'→3' (mRNA lido) |
| **Inicio** | Promotor no DNA | Codon AUG |
| **Termino** | Sequencia terminadora | Codon STOP |

---

## 5. Passo a Passo para Desenhar na Lousa

**Parte 1 — Transcricao:**

**Passo 1** — Desenhe o nucleo com a carioteca (envelope nuclear) e um poro nuclear

**Passo 2** — Dentro do nucleo, desenhe o DNA (dupla helice parcialmente aberta)

**Passo 3** — Adicione a RNA polimerase na fita molde, com o mRNA nascente saindo

**Passo 4** — Mostre o processamento: introns cortados (X), exons unidos, cap 5' e poli-A

**Passo 5** — Seta saindo pelo poro nuclear → mRNA maduro no citoplasma

**Parte 2 — Traducao:**

**Passo 6** — Fora do nucleo, no citoplasma: desenhe o ribossomo sobre o mRNA

**Passo 7** — Marque os 3 sitios (E, P, A) e os tRNAs com seus anticodons

**Passo 8** — Mostre a cadeia peptidica crescendo a medida que o ribossomo avanca

**Passo 9** — Codon STOP sem tRNA correspondente = proteina liberada

## 6. Erros Classicos

> [!warning] Erro 1 — Traducao no nucleo
> A traducao ocorre no CITOPLASMA (nos ribossomos livres ou no reticulo endoplasmico rugoso).
> O mRNA PRECISA SAIR do nucleo antes da traducao comecar.

> [!warning] Erro 2 — Trocar codon por anticodon
> **Codon** = sequencia de 3 bases no mRNA
> **Anticodon** = sequencia complementar no tRNA
> O tRNA CARREGA o aminoacido e RECONHECE o codon pelo seu anticodon.

> [!warning] Erro 3 — Timina no RNA
> No RNA nao existe Timina (T). A Adenina (A) do DNA pareia com **Uracila (U)** no RNA.

> [!warning] Erro 4 — Esquecer o processamento do pre-mRNA
> O que sai do nucleo NAO e o transcrito primario bruto.
> Ha splicing + cap 5' + poli-A antes de o mRNA sair.
